
Backend

# 1. Клонируем/создаем проект

# 2. Создаем виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate  # Windows

# 3. Устанавливаем зависимости
pip install -r requirements.txt

# 4. Копируем .env
cp .env.example .env
Редактируем DATABASE_URL если нужно

# 5. Запускаем PostgreSQL (docker или локально)
docker-compose up -d db

# 6. Создаем миграции
alembic init alembic
Редактируем alembic.ini: sqlalchemy.url = ваш DATABASE_URL
alembic revision --autogenerate -m "Initial migration"
alembic upgrade head

# 7. Запускаем сервер
uvicorn app.main:app --reload

Критерии:

Использование инструмента для миграций - 1 балл

CRUD-операции для всех сущностей (минимальный их набор описан во втором домашнем задании) - 2 балла
Валидация входных данных и обработка ошибок - 1 балл
Авторизация и контроль доступа - 1 балл

Тестирование
Написаны unit и интеграционные тесты, тестовое покрытие достигает как минимум 50% - 1-2 балла

Frontend

# 1. Клонируем/создаем проект

# 2. Устанавливаем зависимости
npm install

# 3. Запускаем фронт
npm run dev
всё запустится на localhost:5173
